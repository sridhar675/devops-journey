# Linux Cheatsheet

| Command | What it does |
|---|---|
| `pwd` | Show the current folder (check this first when a path fails) |
| `ls -a` | List files, including hidden ones |
| `cd <folder>` | Move into a folder |
| `cat <file>` | Print a file |
| `nano <file>` | Edit a file (Ctrl+O, Enter to save, Ctrl+X to exit) |
| `find ~ -name "*text*"` | Search for a file by name |
| `mv <src> <dest>` | Move or rename |
| `rm <file>` | Delete a file |
| `mkdir -p <path>` | Create a folder and any parents |
| `touch <file>` | Create an empty file |
| `cat > file << 'EOF'` | Write a multi-line file from the terminal |

Tip: press Tab to complete names and avoid typos.
